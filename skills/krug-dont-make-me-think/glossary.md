# 术语表 — Don't Make Me Think, Revisited

**Accessibility** — 让不同能力的人能感知、理解、导航和操作产品，是基础质量而非附加功能。 (Ch 12、Ch 13)

**Affordance on Touch** — 触屏缺少悬停等线索，必须用位置、外观、反馈和惯例表达可操作性。 (Ch 10)

**Billboard Design** — 像高速路广告牌一样，让层级、重点、分区和点击目标在短暂一瞥中清楚。 (Ch 3)

**Clear Visual Hierarchy** — 用大小、位置、分组和一致性表达重要性与关系。 (Ch 3、Ch 6、Ch 7、Ch 8)

**Clickable Clarity / 可点击性** — 让链接和控件看起来可行动，并能区分当前状态。 (Ch 3、Ch 4)

**Common Courtesy / 礼貌** — 尊重用户时间、信息、意图和控制权，主动减少可避免的负担。 (Ch 11)

**Conventions / 约定** — 复用人已学会的界面模式，减少解释成本。 (Ch 2、Ch 3、Ch 4、Ch 10、Ch 12)

**Do the Right Thing** — 在项目约束下持续做最重要的清晰性、测试和可访问性改进，而非等待完美流程。 (Ch 13)

**Happy Talk / 欢迎废话** — 自我介绍、营销式欢迎和没有用户价值的填充文字。 (Ch 5)

**Home Page Mission** — 首页要同时表达身份、价值、内容范围、入口与可信度。 (Ch 7)

**Instructions / 说明** — 只有当界面无法自明且不能通过改造消除困惑时才保留的最短指导。 (Ch 5)

**Krug's First Law** — 页面应尽可能自明，不让用户为名称、结构和下一步进行不必要思考。 (Ch 1)

**Mobile Trade-offs** — 移动不是缩小桌面版，而是在更少空间、更多情境和触控约束下保留核心价值。 (Ch 10)

**Omit Needless Words** — 删除不服务任务、解释或信任的文字，降低噪声和滚动。 (Ch 5、Ch 11)

**Reservoir of Goodwill** — 用户带着有限耐心进入产品；每次隐藏信息、额外步骤或不体贴行为都会消耗它。 (Ch 11)

**Satisficing / 满意即止** — 用户通常扫描并选择第一个看起来足够可行的选项，而非优化所有选择。 (Ch 2、Ch 4、Ch 9)

**Scanning / 扫描** — 人按标题、关键词、形状和视觉层级快速寻找相关区域，而非逐字阅读。 (Ch 2)

**Self-Evident / 自明** — 用户几乎不需解释就能看出对象是什么、能做什么。 (Ch 1)

**Self-Explanatory / 自解释** — 无法完全自明时，通过少量及时说明让人迅速理解。 (Ch 1)

**Stakeholder Conflict** — 不同部门把首页当稀缺宣传位，导致共同目标被局部利益挤压。 (Ch 7、Ch 8)

**Street Signs and Breadcrumbs** — 用全局导航、局部导航、页面名、当前位置和路径帮助寻路。 (Ch 6)

**Test Early and Often** — 少量、频繁、低成本测试通常比一次大型末期研究更能改变设计。 (Ch 9、Ch 13)

**Trunk Test** — 假设用户从后备箱被放到任意页面，仍应能说出网站、页面、位置、主要区块和可去之处。 (Ch 6)

**Usability Testing** — 观察真实参与者完成代表任务，用行为而非意见发现主要摩擦。 (Ch 8、Ch 9、Ch 12)
