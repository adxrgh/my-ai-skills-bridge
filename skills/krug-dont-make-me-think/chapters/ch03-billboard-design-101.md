# 第 3 章：Billboard Design 101

## 核心思想

页面应在一瞥中表达层级、分区和行动可能性。

## 本章框架

- **Billboard Design**：像高速路广告牌一样，让层级、重点、分区和点击目标在短暂一瞥中清楚。
  - 何时使用：当页面元素都在争夺注意或关系不清时。
  - 如何使用：建立明显层级，按逻辑分组，嵌套要可见，复用约定并消除视觉噪声。
  - 失效方式：靠装饰制造差异，却没有信息层级。
- **Clear Visual Hierarchy**：用大小、位置、分组和一致性表达重要性与关系。
  - 何时使用：当“Billboard Design 101”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Clear Visual Hierarchy”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。
- **Conventions / 约定**：复用人已学会的界面模式，减少解释成本。
  - 何时使用：当“Billboard Design 101”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Conventions / 约定”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。
- **Clickable Clarity / 可点击性**：让链接和控件看起来可行动，并能区分当前状态。
  - 何时使用：当“Billboard Design 101”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Clickable Clarity / 可点击性”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。

## 关键概念

- **Billboard Design**：像高速路广告牌一样，让层级、重点、分区和点击目标在短暂一瞥中清楚。
- **Clear Visual Hierarchy**：用大小、位置、分组和一致性表达重要性与关系。
- **Conventions / 约定**：复用人已学会的界面模式，减少解释成本。
- **Clickable Clarity / 可点击性**：让链接和控件看起来可行动，并能区分当前状态。

## 心智模型

- 把本章看成一个决策过滤器：建立明显层级，按逻辑分组，嵌套要可见，复用约定并消除视觉噪声。
- 当局部界面“看起来合理”却让人迟疑时，回到用户目标、情境和反馈链，而不是继续装饰表面。
- 设计主张必须能被研究证据、行为结果或可用性观察推翻；不能被推翻的主张只是偏好。

## 反模式

- **视觉喊叫**：靠装饰制造差异，却没有信息层级。
- **术语替代证据**：引用框架名称却没有说明用户、任务、约束和验证信号，会让团队产生虚假的确定性。

## Worked Example

把页面主标题、区块标题、正文和次要元数据拉开层级；将同类链接统一样式，让主动作只有一个视觉峰值。

把例子重新应用到自己的产品时，保留同样的推理顺序：先写目标与情境，再写设计动作，最后写可观察的成功/失败信号。

## 关键结论

1. 建立明显层级，按逻辑分组，嵌套要可见，复用约定并消除视觉噪声。
2. 把“Billboard Design”落实为可观察的界面或流程行为，而不是停留在口号。
3. 用真实情境检查“Clickable Clarity / 可点击性”，并记录失败条件。
