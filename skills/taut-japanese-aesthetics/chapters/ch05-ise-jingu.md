# Chapter 5: 伊势神宫

## Core Idea

伊势神宫通过周期性重建保存形式与工艺，使古老传统持续保持新的材料状态。它展示了一种“以更新维持连续性”的机制：保护的对象不是老旧物质本身，而是结构逻辑、工艺能力和共同仪式。

## Frameworks Introduced

- **更新式保存**：以固定周期重建，让材料更新而形式、知识与仪式连续。
  - When to use: 系统、产品或文化资产无法靠原物永久存续时。
  - How: 明确不可变原则、可替换材料、传承角色和更新节奏。
- **结构即表现**：构造本身形成建筑样式，不用附加装饰遮蔽或解释。
  - When to use: 结构与表皮割裂、装饰用于掩盖方案时。
  - How: 暴露受力和连接逻辑，让材料以本来特性工作。
- **土地生成的形式**：伟大建筑应像当地农舍一样从材料、气候和生产经验中生长。
  - When to use: 判断形式是否真正属于场所时。
  - How: 追溯材料来源、当地工艺、维护方式和自然条件。

## Key Concepts

- **式年迁宫**：周期性重建所形成的连续性制度。
- **唯一神明造**：伊势正殿的特定建筑样式。
- **材料原真**：木、茅草、金属与石材不靠油漆掩盖自身性质。
- **纯粹平衡**：结构、材料和比例互相强化，没有多余附加物。
- **活的古典**：古老形式不成为废墟，而在更新中持续使用。

## Mental Models

- 把长期保存设计成一套更新协议，而不是冻结状态。
- 每增加一层表面处理，都追问它是否遮蔽材料和结构事实。
- 判断地方性时，向普通生产建筑和维护实践追根，不只看纪念性建筑。

## Anti-patterns

- **遗迹崇拜**：把材料变旧误认为历史真实性的唯一形式。
- **装饰补救**：结构关系不成立时，用表皮增加“文化感”。
- **材料伪装**：用油漆与覆盖层抹掉材料特性。

## Worked Example

伊势神宫约每二十年在相邻地点重建。新建筑遵循既定样式，匠人准备优质木材并重复工艺。单件木料会消失，但比例、构造、仪式和技能在代际协作中延续。它把保存从“保住这块木头”转换为“保住产生这座建筑的能力”。

## Key Takeaways

1. 连续性可以通过更新实现，不必依赖物质冻结。
2. 真正可持续的是规则、能力和传承机制。
3. 结构与材料诚实时，装饰需求会显著下降。
4. 地方形式来自土地、生产与维护，而不是视觉标签。
5. 原始、纯粹与现代并不矛盾。
