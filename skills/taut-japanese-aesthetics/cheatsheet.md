# Cheatsheet

## 核心决策

| 当你看到 | 先做 | 因为 |
|---|---|---|
| “传统风格”参考 | 写出它原来解决的问题 | 外形不是可迁移原理 |
| 可放在任何地方的现代方案 | 检查风土、生活、经济、社会 | 地方性来自约束响应 |
| 一眼很震撼但很快疲劳 | 删除无关系的刺激 | 元素数量不能形成整体 |
| 结构薄弱、装饰很多 | 回到构造、材料与用途 | 装饰不能补偿建筑失败 |
| 新技术进入旧场景 | 对比光、声、距离和动作 | 媒介会重写体验关系 |
| “保护”意味着永不更换 | 设计更新与传承协议 | 能力连续有时比材料连续重要 |
| 跨文化强判断 | 标注来源与翻译链 | 洞见不等于事实无误 |

## 桂离宫还是日光

| 维度 | 桂离宫路线 | 日光路线 |
|---|---|---|
| 创作 | 专业自主、反复思考 | 权力命令、执行预设 |
| 组织 | 部分自主、关系协调 | 元素累加、强制统一 |
| 感知 | 渐次显露、引发思考 | 一次展示、视觉疲劳 |
| 材料 | 克制、结构诚实 | 表面化、装饰补救 |
| 目标 | 长期使用与理解 | 炫耀与即时效果 |

## 四面研究

1. **社会**：谁使用？家庭与劳动如何变化？
2. **健康**：身体、通风、采暖、清洁是否成立？
3. **技术**：材料、结构、维护是否匹配？
4. **费用**：建造和长期运行是否可承受？

缺一面，不制定标准。

## 快速气味

- 只能用风格名解释：尚未找到原理。
- 只有展示面成立：正面主义。
- 细节各自精彩，彼此无关：效果总和。
- 新技术让原有色彩、动作或声音失真：媒介失配。
- 传统被封存但没人会继续制作：保存了物，丢了能力。
- 外来者说得锋利但来源单一：保留洞见，复核史实。
