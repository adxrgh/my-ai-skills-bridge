# Glossary

**部分因整体增值** — 局部在整体关系中获得超出单体用途的艺术价值。（Ch 2）

**材料赋色** — 依靠天然材料与加工方式形成色彩，而非附加图案。（Ch 2）

**材料原真** — 让材料按自身质地、气味、老化与结构能力工作。（Ch 5, Ch 8）

**二元化** — 单纯明快与浮夸装饰两条价值路线在日本建筑中的对立。（Ch 8）

**风土现代性** — 现代形式由当地自然、生活、经济和社会条件生成。（Ch 1, Ch 4）

**古典性** — 形式经过长期提炼，摆脱偶然、个性炫示和表面样式。（Ch 2）

**关联性建筑** — 把建筑理解为环境、空间、材料、行为之间的关系网络。（Ch 1-3）

**活的古典** — 古老形式通过持续使用和更新保持当代生命。（Ch 5-6）

**活传统** — 仍在日常生活中塑造行为、解决问题并产生新形式的传统。（Ch 6）

**渐次显露** — 通过遮挡、转折和局部预览，使体验按时间展开。（Ch 2-3）

**结构诚实** — 构造、连接和受力逻辑直接参与形式表达，不被表皮遮蔽。（Ch 5, Ch 8）

**式年迁宫** — 伊势神宫以固定周期重建，传递结构、工艺与仪式的制度。（Ch 5）

**世界性** — 扎根具体条件，却因原理清楚而可被不同文化理解和迁移。（Ch 3, Ch 7）

**实用超越** — 完整满足用途后，以关系、节奏和感知把功能提升为精神体验。（Ch 2-3）

**外来影响消化** — 将外部形式按本地风土、材料和用途重新组织成统一体。（Ch 4, Ch 8）

**永恒之美** — 以纯粹、有力的方式回应作品所受全部真实约束，而非保持固定外形。（Ch 8）

**更新式保存** — 保存产生事物的规则、能力和传承机制，而非冻结每件材料。（Ch 5）

**再发现** — 借新的视角辨认本土文化中被习惯遮蔽的价值，同时校准观察者偏见。（Ch 1, Ch 10）

**正面主义** — 把建筑当图像，只为展示面设计并牺牲真实使用关系。（Ch 3）

**自由个体的共同体** — 各部分保持独立目的，通过关系形成协调、自足的整体。（Ch 3, Ch 7-8）
