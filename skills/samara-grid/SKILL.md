## Core Frameworks & Mental Models

### 1. The Constituent Anatomy Framework (Ch 02)
Every grid system is composed of seven distinct spatial parts:
1. **Format**: The outer boundary, page dimension, or screen frame.
2. **Margins**: Inactive buffer space surrounding the live area.
3. **Columns**: Vertical alignments that contain text and imagery.
4. **Gutters**: Inactive channels separating adjacent columns or modules.
5. **Flowlines**: Horizontal alignment guides across columns that establish starting points for text/imagery.
6. **Modules / Spatial Zones**: Rectangular divisions created by column and flowline intersections.
7. **Markers**: Reserved zones for pagination (folios), running headers, and navigation.

### 2. The Four Grid Typologies Matrix (Ch 02)
Match content density to the appropriate structural architecture:
- **Single-Column (Manuscript Grid)**: Continuous, linear reading (novels, essays, reports).
- **Multi-Column Grid**: Multi-layered, discontinuous editorial content (magazines, websites).
- **Modular Grid**: Tabular, data-dense, image-heavy information (catalogs, schedules, dashboards).
- **Hierarchic Grid**: Custom organic structures based on unique, fixed content elements.

### 3. The Content-First Grid Derivation Method (Ch 03)
Build grids from the inside out based on typography rather than arbitrary page divisions:
1. **Determine Body Typography**: Select font, point size, and leading based on reading distance.
2. **Establish Line Measure**: Target **55–75 characters per line** (10–12 words) for optimal reading comfort.
3. **Calculate Live Area & Column Math**: Use $\text{Live Area} = (N \times \text{Column Width}) + ((N - 1) \times \text{Gutter})$.
4. **Lock Baseline Grid**: Set vertical grid increment equal to body text leading ($10\text{pt type on } 14\text{pt leading} \rightarrow 14\text{pt baseline grid}$). Lock all headings, subheads, and image heights to integer multiples of the baseline leading.

### 4. The Multi-Page Pacing Matrix (Ch 04)
Alternate visual density across spreads to maintain engagement:
- **Phase 1 (Expansion)**: High impact, full-bleed image, generous white space, single large headline.
- **Phase 2 (Compression)**: High density, strict multi-column text layout, locked baseline grid.
- **Phase 3 (Climax)**: Balanced hybrid layout, pull quotes, strategic grid violation.

### 5. The Non-Orthogonal Architecture Taxonomy (Ch 07)
Systems beyond standard X/Y Cartesian grid matrices:
- **Organic Relational**: Position element B relative to the boundary of element A (Domino positioning).
- **Radial & Concentric**: Align elements along circular rays or concentric orbital rings expanding from a focal hub.
- **Grid Deconstruction Operations**:
  - *Splicing*: Cut columns horizontally and slide sections sideways.
  - *Deformation*: Warp straight grid lines into curved or perspective paths.
  - *Dislocation*: Offset adjacent column baselines out of phase.
  - *Interference / Denial*: Drop heavy visual shapes directly across column boundaries.

### 6. The Anchor-and-Path Usability Model (Ch 09)
Preserve functional usability in experimental or deconstructed layouts:
1. **Unambiguous Anchor Point**: 1 prominent starting visual node (oversized number or dominant headline).
2. **Directional Path**: Numbered steps (01 $\rightarrow$ 02 $\rightarrow$ 03) or vector lines guiding the eye through non-linear layout space.
3. **Isolating Sanctuary**: Clean, high-contrast, un-distorted rectangular zone reserved for critical functional text (dates, venue, contact links).
