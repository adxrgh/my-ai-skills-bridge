# 第 4 章：社会性语义符号

## 核心思想

人通过他人的行为痕迹和社会惯例判断该做什么。

## 本章框架

- **Social Signifiers / 社会性意符**：由他人行为、痕迹和社会约定产生的行动线索。
  - 何时使用：当空间或协作产品缺少明确规则但存在群体行为时。
  - 如何使用：识别队列、磨损痕迹、已读状态等社会线索，保留有用信号并防止误导。
  - 失效方式：把所有行为线索清理掉，迫使每个人重新探索。
- **Coping / 应对机制**：人在复杂系统中借助惯例、外部记忆、分工和近似规则维持行动。
  - 何时使用：当“社会性语义符号”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Coping / 应对机制”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。
- **Conceptual Simplicity / 概念简单**：用少数稳定规则和清晰模型组织复杂能力，使人能够预测。
  - 何时使用：当“社会性语义符号”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Conceptual Simplicity / 概念简单”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。

## 关键概念

- **Social Signifiers / 社会性意符**：由他人行为、痕迹和社会约定产生的行动线索。
- **Coping / 应对机制**：人在复杂系统中借助惯例、外部记忆、分工和近似规则维持行动。
- **Conceptual Simplicity / 概念简单**：用少数稳定规则和清晰模型组织复杂能力，使人能够预测。

## 心智模型

- 把本章看成一个决策过滤器：识别队列、磨损痕迹、已读状态等社会线索，保留有用信号并防止误导。
- 当局部界面“看起来合理”却让人迟疑时，回到用户目标、情境和反馈链，而不是继续装饰表面。
- 设计主张必须能被研究证据、行为结果或可用性观察推翻；不能被推翻的主张只是偏好。

## 反模式

- **无痕设计**：把所有行为线索清理掉，迫使每个人重新探索。
- **术语替代证据**：引用框架名称却没有说明用户、任务、约束和验证信号，会让团队产生虚假的确定性。

## Worked Example

草地上的踩踏路径揭示真实通行需求。与其反复围挡，可将其视为研究证据，调整正式路径并验证安全影响。

把例子重新应用到自己的产品时，保留同样的推理顺序：先写目标与情境，再写设计动作，最后写可观察的成功/失败信号。

## 关键结论

1. 识别队列、磨损痕迹、已读状态等社会线索，保留有用信号并防止误导。
2. 把“Social Signifiers / 社会性意符”落实为可观察的界面或流程行为，而不是停留在口号。
3. 用真实情境检查“Conceptual Simplicity / 概念简单”，并记录失败条件。
