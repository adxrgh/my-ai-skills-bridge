# 术语表 — 设计心理学2：如何管理复杂

**Challenge / 挑战** — 在效率、透明度、安全、文化和组织利益冲突下持续管理复杂性。 (Ch 9)

**Complicatedness / 费解感** — 人面对结构、控制或解释混乱时产生的主观困难；它不同于客观复杂性。 (Ch 1)

**Conceptual Simplicity / 概念简单** — 用少数稳定规则和清晰模型组织复杂能力，使人能够预测。 (Ch 1、Ch 2、Ch 4)

**Coping / 应对机制** — 人在复杂系统中借助惯例、外部记忆、分工和近似规则维持行动。 (Ch 2、Ch 4、Ch 8)

**Designing Waiting / 等待设计** — 通过预期、解释、进度、控制感和有价值活动改善等待体验。 (Ch 7)

**False Simplicity / 虚假简单** — 删去可见控件却把负担转移到记忆、模式、步骤或支持渠道。 (Ch 2、Ch 3)

**Journey / 旅程** — 用户跨时间和触点完成目标的连续经历，而不是单个屏幕。 (Ch 3、Ch 6、Ch 7)

**Necessary Complexity / 必要复杂性** — 复杂任务本身具有不可消除的结构；目标是使其可理解和可管理，而不是假装不存在。 (Ch 1、Ch 8、Ch 9)

**Partnership / 人机伙伴关系** — 人负责目标、价值与例外判断，系统负责计算、记忆和稳定执行的互补分工。 (Ch 5、Ch 6、Ch 8)

**Service System / 服务系统** — 由人、渠道、规则、后台流程与触点共同完成结果的整体。 (Ch 3、Ch 6、Ch 9)

**Sociable Design / 善于交际的设计** — 让产品以合乎礼仪、可理解并尊重关系的方式沟通意图和状态。 (Ch 5、Ch 7)

**Social Signifiers / 社会性意符** — 由他人行为、痕迹和社会约定产生的行动线索。 (Ch 4、Ch 5)
