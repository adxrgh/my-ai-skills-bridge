# 设计心理学2：如何管理复杂

**作者**：Donald A. Norman / 唐纳德·A·诺曼 | **页数/章节**：四卷套装 EPUB 中的第 2 卷 | **章节数**：9 | **生成日期**：2026-08-21

## 核心框架与心智模型

- **Necessary Complexity / 必要复杂性**：复杂任务本身具有不可消除的结构；目标是使其可理解和可管理，而不是假装不存在。
- **Conceptual Simplicity / 概念简单**：用少数稳定规则和清晰模型组织复杂能力，使人能够预测。
- **Social Signifiers / 社会性意符**：由他人行为、痕迹和社会约定产生的行动线索。
- **Sociable Design / 善于交际的设计**：让产品以合乎礼仪、可理解并尊重关系的方式沟通意图和状态。
- **Service System / 服务系统**：由人、渠道、规则、后台流程与触点共同完成结果的整体。
- **Designing Waiting / 等待设计**：通过预期、解释、进度、控制感和有价值活动改善等待体验。
- **Coping / 应对机制**：人在复杂系统中借助惯例、外部记忆、分工和近似规则维持行动。

### 应用纪律

1. 先明确用户、目标、情境与约束，再选择框架；不要反过来为框架寻找例子。
2. 将设计主张写成“当 X 时做 Y，因为 Z”，并指定可观察的成功与失败信号。
3. 区分作者的框架、来源中的案例和你当前项目的假设；三者不能互相冒充。
4. 如果新研究证据与现有方案冲突，修改模型和方案，不修改用户事实。
