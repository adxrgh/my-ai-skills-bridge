# 第 5 章：人物、地点、事件

## 核心思想

人珍视的往往不是物本身，而是它连接的人、地点、事件和自我叙事。

## 本章框架

- **Memory and Self / 记忆与自我**：物品因承载经历、关系和身份而获得超越功能的价值。
  - 何时使用：当设计个人档案、纪念、收藏或长期数据时。
  - 如何使用：保留来源、时间、关系和用户自己的表达，让系统帮助回忆而不篡改意义。
  - 失效方式：用自动摘要取代原始记忆与用户叙述。
- **Narrative / 叙事**：把事件连接成可解释意义的结构，影响反思层体验。
  - 何时使用：当“人物、地点、事件”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Narrative / 叙事”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。
- **Reflective Design / 反思层设计**：由意义、身份、记忆、文化和叙事形成的长期评价。
  - 何时使用：当“人物、地点、事件”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Reflective Design / 反思层设计”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。

## 关键概念

- **Memory and Self / 记忆与自我**：物品因承载经历、关系和身份而获得超越功能的价值。
- **Narrative / 叙事**：把事件连接成可解释意义的结构，影响反思层体验。
- **Reflective Design / 反思层设计**：由意义、身份、记忆、文化和叙事形成的长期评价。

## 心智模型

- 把本章看成一个决策过滤器：保留来源、时间、关系和用户自己的表达，让系统帮助回忆而不篡改意义。
- 当局部界面“看起来合理”却让人迟疑时，回到用户目标、情境和反馈链，而不是继续装饰表面。
- 设计主张必须能被研究证据、行为结果或可用性观察推翻；不能被推翻的主张只是偏好。

## 反模式

- **替用户定义意义**：用自动摘要取代原始记忆与用户叙述。
- **术语替代证据**：引用框架名称却没有说明用户、任务、约束和验证信号，会让团队产生虚假的确定性。

## Worked Example

照片应用可按时间地点聚合素材，但标题、删选和故事解释应由用户控制；模型建议只作为可追溯候选。

把例子重新应用到自己的产品时，保留同样的推理顺序：先写目标与情境，再写设计动作，最后写可观察的成功/失败信号。

## 关键结论

1. 保留来源、时间、关系和用户自己的表达，让系统帮助回忆而不篡改意义。
2. 把“Memory and Self / 记忆与自我”落实为可观察的界面或流程行为，而不是停留在口号。
3. 用真实情境检查“Reflective Design / 反思层设计”，并记录失败条件。
