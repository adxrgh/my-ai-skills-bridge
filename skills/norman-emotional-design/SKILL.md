# 设计心理学3：情感化设计

**作者**：Donald A. Norman / 唐纳德·A·诺曼 | **页数/章节**：四卷套装 EPUB 中的第 3 卷 | **章节数**：7 | **生成日期**：2026-08-21

## 核心框架与心智模型

- **Visceral Design / 本能层设计**：作用于感知与即时情绪的外形、触感、声音和第一印象。
- **Behavioral Design / 行为层设计**：围绕使用、功能、可理解性和操作感受形成的体验。
- **Reflective Design / 反思层设计**：由意义、身份、记忆、文化和叙事形成的长期评价。
- **Positive Affect / 积极情感**：拓宽注意与创造性、提高容错感受的积极情绪状态。
- **Memory and Self / 记忆与自我**：物品因承载经历、关系和身份而获得超越功能的价值。
- **Anthropomorphism / 拟人化**：人倾向于把意图和情感归因于会行动、回应的对象。
- **Emotional Machines / 情感化机器**：能够感知、表达或调节情感线索的系统。

### 应用纪律

1. 先明确用户、目标、情境与约束，再选择框架；不要反过来为框架寻找例子。
2. 将设计主张写成“当 X 时做 Y，因为 Z”，并指定可观察的成功与失败信号。
3. 区分作者的框架、来源中的案例和你当前项目的假设；三者不能互相冒充。
4. 如果新研究证据与现有方案冲突，修改模型和方案，不修改用户事实。
