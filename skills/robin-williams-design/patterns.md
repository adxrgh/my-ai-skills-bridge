# Patterns — Robin Williams Design Book

This file catalogs the reusable design patterns (procedures, checklists, recipes) that can be applied to any layout task. Organized by the functional job each pattern performs.

## 1. The Master Workflow (5-Step Design Process)
*Source: Ch 13; formalizes the CRAP application. Use on ANY new or redesign.*

1. **Start with the focal point** — decide what the reader sees first; create a strong-contrast center unless you deliberately want harmony.
2. **Group the information** (proximity) — logical grouping; closeness shows relationship; set different spacing to signal which groups are related.
3. **Establish clear alignment** — pick one alignment; reinforce obvious edges (photo edges, rules) by aligning other elements to them.
4. **Create or amplify repetition** — bold type, rules, ornaments, spatial layout; push existing consistency further.
5. **Create strong contrast** — black-and-white clarity. If all elements are big/bold/fancy, there's no contrast.

Always end by checking the result against all four principles.

## 2. The "Don't Be a Wimp" Checklist
*Source: Ch 6. Courage checklist for timid designs.*
- Leave generous blank space (rest for the eye).
- Prefer asymmetric / non-centered layouts.
- Use genuinely large or genuinely small type when appropriate.
- Use large or small images if they support the design.
- When contrast-ting, make differences extreme, not timid.

## 3. The Squint / Stop-Count Test (Proximity)
*Source: Ch 2.*
- Squint at the page; count eye-stops.
- More than 3–5 stops on a simple page → regroup isolated elements.
- Equal spacing everywhere → imply everything is related (usually wrong).

## 4. The Alignment-Line Test
*Source: Ch 3, 8.*
- Draw vertical/horizontal lines through every element.
- Every element should sit on a shared line with another element.
- Look for: headline centered over left-aligned text (fix → left-align both), captions centered under photos (fix → align), photos overshooting columns (trim), weak/broken edges.
- Check for trapped whitespace between photos and text.

## 5. The Similarity Diagnostic
*Source: Ch 10, 12, 14. When a type pairing (or any design) feels wrong.*
- Hunt the SIMILARITIES, not the differences.
- Ask: both ALL CAPS? same size? similar weight? same structure (category)? same shape (both scripts/italics)? same roman form?
- Name the problem → the solution follows (contrast that specific axis).
- Also check for competing focal points (larger-but-thinner vs smaller-but-bolder).

## 6. Font Pairing Playbook
*Source: Ch 11, 12.*
1. Choose fonts from TWO DIFFERENT categories (Robin's rule: never two from the same category).
2. Serif + sans is the time-tested baseline.
3. Structure contrast alone is weak — reinforce with size and/or weight.
4. Two type categories + caps-vs-lowercase + roman-vs-italic + size + weight = a rich, intentional combo.
5. For two-sans problems: use different members of ONE sans family (e.g., Condensed Ultra Light + Heavy + Regular Italic).
6. Add a true black/text-heavy weight to your library — computer defaults (Helvetica/Arial) are too weak for contrast.
7. To combine script/italic, pair with a ROMAN that has a different structure (optionally heavier).

## 7. The Six Type Contrasts (reference)
*Source: Ch 12.*
| Contrast | How to make it strong | Pitfall |
|----------|----------------------|---------|
| Size | 20→30pt, not 12→14pt; small-on-huge also works | too-close sizes = conflict |
| Weight | regular vs. very bold, not semibold | semibold = looks like a mistake |
| Structure | two different categories | same-category fonts conflict |
| Shape | caps vs. lowercase; roman vs. italic | two scripts/italics conflict |
| Direction | horizontal text vs. tall columns | angled type needs a stated reason |
| Color | warm advances (use little); cool recedes (use more) | equal warm/cool; ALL-CAPS-readable issues |

## 8. Fixing the "Gray Text Page"
*Source: Ch 12.*
- Bold the headings/subheads to add "color."
- Set a quote, paragraph, or small story in a distinctly different "color" (texture).
- Use very heavy bold for key phrases (optionally size them to match body optically).
- Vary tracking/leading/letter-spacing/structure to create different type "colors."
- This also organizes content (separates stories/items).

## 9. Project-Specific Receipts
*Source: Ch 8.*

**Business card**: remove non-essentials; drop "phone/email/website" words; 8–9pt type; horizontal or vertical; strong focal point; one alignment; design with letterhead+envelope.

**Letterhead/envelope**: design together with card; #10 (9½×4") or C4 (110×220mm); one dominant element on all three; one alignment; optional second page with one small repeated element.

**Flyer**: ONE focal point; contrast-y subheads (else thrown away); repeat the headline font somewhere; one alignment; context matters (mailed vs. kiosk); be brave with scale/fonts.

**Newsletter**: one alignment consistently; first paragraph never indented (1em indents otherwise); no Helvetica/Arial (use weighty sans + classic Oldstyle serif body); organize whitespace; masthead sets tone.

**Brochure**: fold a dummy first; front/back panel widths differ; keep important info out of the crease; new paragraphs spaced via paragraph settings, not double-Enter; all four principles.

**Postcard**: be different/serial/specific/concise/colorful; determine the impression (luxury vs. bargain); contrast is your best friend.

**Newspaper ad**: whitespace = the contrast weapon on a crowded page; avoid delicate serifs/thin rules (ink spread); avoid reverse text on cheap paper (or use a no-thin-strokes font, slightly larger); copy = blank + clever headline + clear CTA + concise.

**Resume**: bold headers (scannable hierarchy); follow punctuation with matching style; one alignment; consistent date placement; repeat accent color; match the medium (mail/web/print).

**Branding**: one signature image/style repeated on every piece; it's the branding engine.

## 10. Typography Hygiene Checklist (amateurl-tell removers)
*Source: Ch 9.*
- One space after punctuation (never two).
- Curly quotes, 9-shaped apostrophes; correct placement.
- Hyphen vs en dash (ranges) vs em dash (breaks); never double-hyphen.
- No ALL-CAPS for emphasis (word-shape reading); use italics/bold/size/color.
- Never default-underline.
- Kern large type manually (visual, not math).
- No widows/orphans.
- 1em paragraph indents; indent-OR-space (not both); no first-paragraph indent.
- Punctuation after styled text matches the style; punctuation in/out of parens by grammar.
- Bullets (not hyphens) for lists; generous even space around boxed text.
- ALL-CAPS only with a stated design reason.

## 11. The Tracing-Paper Redesign Exercise
*Source: Ch 13. The training loop for building your eye.*
- Find a bad ad (newspaper/magazine/web).
- Trace it; redraw misplaced parts with clear alignment lines.
- Tighten proximity; make the focal point truly central.
- Caps → lowercase; bolder some, smaller some, larger others.
- Remove obvious junk; the more thorough, the better the result.
- When working with colors, also sample palettes from photos and choose schemes before starting a multi-part project (Ch 7).

## 12. Color Palette Selection Path
*Source: Ch 7.*
- Seasonal → analogous (hot=summer, icy=winter, orange/brown=autumn, green=spring).
- Company colors → start there + tints/shades.
- Logo colors → use a split-complementary.
- Photo present → eyedropper a color, build analogous (calm) or complementary (energetic).
- Recurring project → fixed palette reused across issues; chosen BEFORE starting.
- Keep values distinct (avoid vibration); warm advances / cool recedes; use less warm.
- Tints/shades of any scheme avoid clichés (Christmas green/red, kid-toy primaries).
