# Glossary — Robin Williams Design Book (写给大家看的设计书)

## Design Principles (设计原则)
- **CRAP**: the acronym for the 4 basic principles — Contrast, Repetition, Alignment, Proximity. (Note: the book's own footnote acknowledges the acronym is impolite; it's commonly known as "CRAP" online.)
- **对比 (Contrast)**: elements that differ must differ *obviously* — timid differences read as mistakes (conflict).
- **重复 (Repetition)**: repeating visual elements (color, shape, font, line, space) to unify a design.
- **对齐 (Alignment)**: every element has a visual connection to another element; nothing placed arbitrarily.
- **亲密性 (Proximity)**: related items are physically grouped into visual units; unrelated items are separated.

## Color (颜色)
- **色轮 (Color wheel)**: 12 colors — 3 primaries, 3 secondaries, 6 tertiaries.
- **三原色 (Primary colors)**: yellow, red, blue — cannot be mixed.
- **三间色 (Secondary colors)**: green, purple, orange.
- **第三色 (Tertiary colors)**: yellow-orange, blue-green, etc.
- **互补 (Complementary)**: opposite colors on the wheel; one dominant + one accent.
- **三色组 (Triad)**: 3 colors equally spaced (e.g., red/yellow/blue, green/orange/purple).
- **分裂互补三色组 (Split-complementary)**: a color + the two colors flanking its complement.
- **类似色 (Analogous)**: adjacent colors on the wheel.
- **单色 (Monochromatic)**: one hue + its tints and shades.
- **色调 (Hue)**: pure color.
- **亮色 (Tint)**: hue + white.
- **暗色 (Shade)**: hue + black.
- **色质 (Value)**: a color's particular lightness/darkness; values too close cause visual vibration.
- **暖色 (Warm)**: contains red/yellow — advancing, grabs attention.
- **冷色 (Cool)**: contains blue — receding, works as background.
- **CMYK**: Cyan/Magenta/Yellow/Key — 4-color process for print.
- **RGB**: Red/Green/Blue — light model for screens.

## Typography (字体)
- **字体类别 (Type categories)**: Oldstyle, Modern, Slab serif, Sans serif, Script, Decorative.
- **衬线 (Serif)**: small strokes at letter ends. **无衬线 (Sans serif)**: no serifs ("sans" = without).
- **旧式体 (Oldstyle)**: diagonal stress, moderate thick/thin transition, angled serifs — best for body text.
- **现代体 (Modern)**: vertical stress, severe thick/thin, thin horizontal serifs — striking at large sizes, poor for body.
- **粗衬线体 (Slab serif)**: heavy uniform strokes, little thick/thin (Clarendon/Egyptian).
- **手写体 (Script)**: handwritten look — use sparingly, never ALL CAPS.
- **花体 (Decorative)**: special-occasion display faces — use in limited amounts.
- **粗/细过渡 (Thick/thin transition)**: stroke contrast within letters (moderate/severe/none).
- **强调线 (Stress)**: imaginary line through the thinnest parts of curves (diagonal in Oldstyle, vertical in Modern).
- **x字母高度 (x-height)**: height of the lowercase x.
- **扩展/压缩字体 (Extended/condensed)**: spread-out vs. squeezed-in faces.
- **协调 (Harmonious)**: one type family, little variation — safe, formal, often dull.
- **冲突 (Conflict)**: similar-but-not-same typefaces — always avoid.
- **对比 (Contrast, type)**: very different typefaces — the goal. Six ways: size, weight, structure, shape, direction, color.
- **字距调整 (Kerning)**: adjusting space between character pairs for visual evenness.
- **字距追踪 (Tracking)**: uniform letter-spacing adjustment across text.
- **行间距 (Leading)**: vertical space between lines.
- **寡妇 (Widow)**: final line of a paragraph with <7 characters (or a hyphenated fragment).
- **孤儿 (Orphan)**: a paragraph's last short line stranded at the top of the next column/page.
- **em 空格 (Em space)**: space equal to the type point size; standard paragraph indent ≈ 1 em (≈2 spaces).
- **连字符 (Hyphen)**: joins words (-).
- **一字线 (En dash)**: duration/range (–).
- **破折号 (Em dash)**: sudden thought change (—).
- **印刷引号 (Curly quotes)**: "66/99" shaped quotes; typewriter quotes are amateur.
- **撇号 (Apostrophe)**: single closing quote shape (9); marks possession or omission.
- **OpenType**: font format with ~16,000 glyphs per font.

## Layout (布局)
- **中心点 (Focal point)**: the dominant element the eye sees first.
- **空白 (White space)**: intentional empty space; organized whitespace is a design element.
- **截留的空白 (Trapped whitespace)**: ugly-shaped blank space between related elements that should be removed.
- **刊头 (Masthead)**: the title block of a newsletter that sets the tone.
- **可视单元 (Visual unit)**: items grouped by proximity perceived as one entity.
- **基线 (Baseline)**: invisible line beneath the type.
- **正文 (Body text)**: main reading text, 9–12pt typically.

## Other
- **VIP**: "Untrained person" (author's playful term: 未经过视觉训练的人).
- **Wildflower Theory of Color (野花理论)**: natural color combinations look fine together; only value-closeness causes problems.
- **约书亚树 (Joshua tree)**: the book's opening metaphor — once you can name something, you see it everywhere.
