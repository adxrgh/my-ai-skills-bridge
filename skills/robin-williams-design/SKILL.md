# Robin Williams: The Non-Designer's Design Book

A design skill distilled from Robin Williams's classic book (Chinese edition: 写给大家看的设计书).
It converts non-designers into designers who can create professional, clear, attractive layouts by
applying four simple principles.

## When to use
- Creating or redesigning any layout: flyer, poster, business card, letterhead, newsletter, brochure, postcard, newspaper ad, resume, cover page, slides.
- Choosing colors or pairing typefaces.
- Critiquing an existing design and proposing concrete fixes.
- Building brand identity (cards + letterhead + envelope, repeated signature elements).

## The 4 Basic Principles (CRAP)
1. **Contrast (对比)** — If elements differ, make them VERY different. Timid differences (12pt vs 14pt, regular vs semibold) read as mistakes. Contrast organizes hierarchy and draws the eye.
2. **Repetition (重复)** — Deliberately repeat visual elements (fonts, colors, rules, bullets, spacing, motifs) to unify the piece and add visual interest. Don't overdo it.
3. **Alignment (对齐)** — Nothing placed arbitrarily. One alignment per page; align to the strongest edge (left/right beats centered). Breaking alignment deliberately is OK only when the rest is clearly aligned.
4. **Proximity (亲密性)** — Related items grouped physically into visual units; unrelated items separated. Squint test: more than 3–5 eye-stops on a simple page = too many isolated elements.

**Master rule: Don't be a wimp.** In design (and life): don't fear white space, asymmetry, big/small scale, or strong contrast.

## Type
- **Three relationships**: harmonious (one family — formal, safe, dull), conflict (similar-but-not-same — NEVER), contrast (very different — the goal).
- **Six type contrasts**: size, weight, structure, shape (caps/lowercase, roman/italic), direction, color.
- **Six categories**: Oldstyle (body text), Modern (display), Slab serif (heavy display), Sans serif (get a family with a full weight range), Script (sparingly, never ALL CAPS), Decorative (tiny amounts).
- **Robin's rule**: never put two fonts from the same category on one page.
- **Hygiene**: one space after punctuation; curly quotes & 9-shaped apostrophes; hyphen vs en/em dash; no ALL-CAPS for emphasis; no default underlines; kern large type; no widows/orphans; 1em indents (indent OR paragraph space, not both); first paragraph never indented.

## Color
- **Wheel**: primaries (Y/R/B), secondaries, tertiaries (12 total).
- **Schemes**: complementary, triad, split-complementary, analogous, monochromatic — plus tints/shades versions of any.
- **Warm advances, cool recedes**: use less warm than cool.
- **Print = CMYK; screen = RGB** (edit in RGB, convert at end).
- Keep color *values* distinct to avoid visual vibration. Choose palettes before starting a multi-part project; pull colors from photos with an eyedropper.

## Design Process (use for any task)
1. Start with the **focal point** — what does the reader see first?
2. **Group** information (proximity).
3. Establish clear **alignment**.
4. Create or amplify **repetition**.
5. Ensure strong **contrast** (black-and-white clarity).
