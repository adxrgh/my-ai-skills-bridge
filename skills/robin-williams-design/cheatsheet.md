# Cheatsheet — Robin Williams: The Non-Designer's Design Book

Quick-reference card. Full detail in `chapters/`, `glossary.md`, `patterns.md`.

## The 4 Principles (CRAP)

| Principle | Rule | How | Check |
|-----------|------|-----|-------|
| **Contrast 对比** | If elements differ, make them VERY different. Never timid. | Size, weight, structure, shape, direction, color | Squint: does something grab the eye first? |
| **Repetition 重复** | Repeat visual elements across the whole work. | Fonts, colors, rules, bullets, spacing, motifs | Do all parts feel like one piece? |
| **Alignment 对齐** | Nothing placed arbitrarily; every element connects visually. | One alignment per page; align to strongest edge | Draw alignment lines: do they meet? |
| **Proximity 亲密性** | Related items grouped; unrelated separated. | Physical closeness; paragraph spacing | Squint: 3–5 eye-stops max on simple pages |

**Master rule: DON'T BE A WIMP.** Timid differences = mistakes. Bold differences = intent.

## Type Relationships
- **Harmonious (协调)** — one family, safe/formal/boring. OK when deliberate.
- **Conflict (冲突)** — similar-but-not-same fonts. NEVER. Diagnose by finding similarities.
- **Contrast (对比)** — very different fonts. The goal.

## 6 Type Contrasts
1. **Size** — extreme (20 vs 30pt), never 12 vs 14pt; lowercase lets you go bigger than caps.
2. **Weight** — regular vs heavy, not semibold; get a family with a real black weight.
3. **Structure** — different categories; NEVER two fonts from the same category on one page.
4. **Shape** — caps vs lowercase; roman vs italic; never two scripts or script+italic.
5. **Direction** — horizontal vs tall columns; angled type needs a stated reason.
6. **Color** — warm advances (little goes far), cool recedes (needs volume).

## The 6 Type Categories
| Category | Identify by | Use for |
|----------|-------------|---------|
| Oldstyle 旧式体 | angled serifs, diagonal stress, moderate transition | body text (best) |
| Modern 现代体 | thin horizontal serifs, vertical stress, severe transition | large display |
| Slab 粗衬线体 | heavy uniform strokes (Clarendon/Egyptian) | heavy display, children's books |
| Sans 无衬线体 | no serifs, monoweight | get a family with full weight range |
| Script 手写体 | handwritten | sparingly, never ALL CAPS |
| Decorative 花体 | instantly recognizable | tiny amounts |

## Color Shortcuts
- **Schemes**: complementary (opposite), triad (equally spaced), split-complementary (complement's neighbors), analogous (adjacent), monochromatic (hue + tints/shades).
- **Tint** = hue + white; **Shade** = hue + black.
- **Values too close** = visual vibration — keep distinct.
- **Warm** (red/orange) advances → use little. **Cool** (blue/green) recedes → use more.
- **Print = CMYK; Screen = RGB.** Edit in RGB, convert to CMYK for print.
- Avoid clichés: red+green full-saturation = Christmas; primary triad = kids' toys (use tints/shades).

## Typography Hygiene (amateur tells)
- ✅ ONE space after punctuation
- ✅ Curly quotes "66/99", 9-shaped apostrophes
- ✅ Hyphen - / En dash – (ranges) / Em dash — (breaks); never --
- ✅ No ALL CAPS for emphasis (we read word shapes)
- ✅ No default underlines (use italics/bold/size/color)
- ✅ Kern large type manually
- ✅ No widows/orphans
- ✅ 1em indent (≈2 spaces); indent OR paragraph space, never both
- ✅ First paragraph never indented; punctuation follows styled text
- ✅ Bullets, not hyphens, for lists

## Key Formulas
- **Focal point**: one dominant element; if everything is big/bold, nothing is.
- **Fix a gray page**: bold headings + a contrasting "color" block (weight/spacing/structure).
- **Font pairing**: two different categories + size/weight/shape reinforcement.
- **Business card**: 8–9pt type, no filler words, one alignment, focal point.
- **Newspaper ad**: whitespace is the contrast weapon; mind ink spread.
- **Brochure**: fold a dummy first; watch panel widths and the crease.
- **Branding**: one signature element repeated everywhere.

## Design Process (5 steps)
1. Focal point → 2. Group (proximity) → 3. Align → 4. Repeat → 5. Strong contrast.
