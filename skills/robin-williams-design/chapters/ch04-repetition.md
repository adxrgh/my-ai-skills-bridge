# Chapter 4: 重复 (Repetition)

## Core Idea
Deliberately repeat visual elements throughout a work — colors, shapes, textures, spatial relationships, line weights, fonts, sizes, images, formats — to unify the design and strengthen its visual appeal. Repetition is "consistency" made intentional.

## Frameworks Introduced
- **Repetition Principle**: Some aspect of the design must be repeated throughout the entire piece. Any aspect the reader can see can serve as a repeated element.
  - When: Always — even single-page documents benefit; multi-page publications depend on it.
  - How: Start with elements that already recur (headings, page numbers, bullets, rules) and push them further — make the repeated element bolder, more prominent, or turn it into a graphic device.
- **Two-step approach**: First find and strengthen *existing* repetition; then *create* new repeating elements (e.g., a special character shown in various sizes/angles/grays, a shape pulled from an illustration).
- **Unity + visual interest**: Repetition both unifies the design and adds visual appeal — and visually interesting work is more likely to be read.

## Key Concepts
- **Repetition ≠ identical copies**: Repeated items can be related but not identical — same font in different colors, same shape in different sizes/angles. "Unity in variety."
- **Corporate identity systems**: Business card + letterhead + envelope must share strong, obvious repeated elements so the recipient connects them to the same person.
- **Partial repetition**: Using only a *part* of a familiar image (e.g., part of a typewriter icon) triggers the reader's memory of the whole — a powerful association technique.
- **Unrelated decorative repetition**: You can add repetition with elements unrelated to the content (e.g., ornamental characters, shapes) as long as it looks deliberate, not messy.
- **Drawing elements across borders**: Pulling a design element past a border or frame unifies two or more sections, foreground with background, or separate publications sharing a theme.

## Mental Models
- **"Repetition = someone's in charge"**: Repetition lends professionalism and authority; readers sense a deliberate design decision.
- **The black dress analogy**: Repetition is like accessorizing — a black dress with red shoes, red lips, and one red flower (repetition) is elegant; adding red hat, earrings, handbag, coat, and top is overkill that destroys contrast and focus.
- **"If everything is consistent, break one element"**: In a highly consistent publication, one deliberately different element draws the reader's attention exactly where you want it.
- **Dedication to repeat**: When designing multi-page documents, the reader should clearly feel pages 3 and 13 belong to the same publication.

## Anti-patterns
- **Unconscious repetition**: Letting consistency happen by accident instead of making it deliberate and strong.
- **Repeating too much**: Too much repetition becomes annoying and muddles the emphasis — contrast disappears.
- **Repeating elements that don't serve the design**: Decorative repetition that looks random rather than intentional.
- **Weak repetition**: Elements that are "sort of" the same (a slightly different bullet style) that read as mistakes.

## Worked Example
**Business card**: Adding one repeated element — a bold typeface — makes the eye jump between bold elements at start and end, keeping attention on the page and unifying the design.

**Multi-page newsletter**: Repeated elements that bind pages: consistent double rule at top, same headline/subhead fonts with consistent space above, single line at bottom of every page, page numbers in the same outer-corner position, consistent top starting point for all content.

**Speaker flyer, two versions**: Version A centers everything (weak). Version B focuses on the speaker: a black band repeated at top and bottom ties the whole flyer together; alignment and contrast principles also applied.

**Recipe cards**: Same format for every recipe (strong structure) allows flexibility elsewhere — e.g., same headline font but different colors, stylish but different body fonts. Structure enables variety.

**Postcard**: Pull the heart shape from the illustration and repeat it on the envelope, RSVP card, and balloons — a family of materials unified without identical repetition.

## Key Takeaways
1. Repetition unifies and strengthens a design — its purpose is unity plus visual impact.
2. Find existing consistency and amplify it; then invent new repeated elements.
3. Repetition can be partial, varied, or decorative — but must look deliberate.
4. Don't overdo it: too much repetition kills contrast and focus.
5. Multi-page documents absolutely require repetition to feel like one piece.
6. Repetition + contrast together form the backbone of strong layouts.
