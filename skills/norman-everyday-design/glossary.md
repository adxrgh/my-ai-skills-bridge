# 术语表 — The Design of Everyday Things / 设计心理学1：日常的设计

**Affordance / 能供性** — 对象与行动者能力之间真实存在的可行动关系；它不等于界面提示。 (Ch 1)

**Conceptual Model / 概念模型** — 用户据以预测系统行为的简化解释；界面应提供连贯的系统形象。 (Ch 3、Ch 6、Ch 7)

**Constraints / 约束** — 通过物理、文化、语义或逻辑关系限制不合适的行动。 (Ch 4、Ch 5)

**Design Thinking / 设计思维** — 先发现正确问题，再以发散和收敛循环寻找、验证解决方案。 (Ch 6)

**Discoverability / 可发现性** — 让用户能够判断有哪些行动、当前状态和下一步可能结果。 (Ch 1)

**Double-Diamond / 双钻** — 问题空间和方案空间各经历一次发散与收敛的过程模型。 (Ch 6)

**Feedback / 反馈** — 及时、可解释地呈现行动已发生以及系统变成了什么状态。 (Ch 4、Ch 5)

**Gulf of Evaluation / 评估鸿沟** — 系统状态与用户理解结果之间的距离。 (Ch 2)

**Gulf of Execution / 执行鸿沟** — 用户意图与可用行动之间的距离。 (Ch 2)

**Human-Centered Design** — 从人的需要、能力与行为出发，通过观察、构思、原型和测试反复收敛的设计过程。 (Ch 1、Ch 6、Ch 7)

**Incremental Innovation / 渐进创新** — 在既有范式内持续优化，风险较低但容易受当前概念模型限制。 (Ch 7)

**Knowledge in the Head / 头脑知识** — 依赖记忆、技能与内化规则的知识，速度快但学习成本高。 (Ch 3)

**Knowledge in the World / 外界知识** — 借助标签、布局、约束、清单和环境提示完成任务的知识。 (Ch 3)

**Mapping / 映射** — 控件、动作与结果之间的对应关系；自然映射减少解释和记忆。 (Ch 3、Ch 4)

**Root Cause Analysis / 根因分析** — 越过操作者表面行为，追查导致失败的系统条件和设计决策。 (Ch 5)

**Seven Stages of Action / 行动七阶段** — 目标、计划、指定、执行、感知、解释、比较组成的行动循环。 (Ch 2)

**Signifier / 意符** — 传达何处以及如何行动的可感知线索。 (Ch 1、Ch 4)

**Slips and Mistakes / 失误与错误** — 失误是执行偏离意图，错误是目标或计划本身不合适；两者需要不同修复。 (Ch 5)

**System Image / 系统形象** — 产品外观、文档、反馈和行为共同呈现给用户的系统解释。 (Ch 7)

**Three Levels of Processing / 加工三层次** — 本能、行为和反思三个相互影响的情感与认知层次。 (Ch 2)
