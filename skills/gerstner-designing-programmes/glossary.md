# Glossary

**Achromatic series / 无彩色序列** — 从白到黑、按可控步长组织的灰阶；是研究结构、次序和对比的基础材料。（Ch 5, 12）

**Chance operation / 偶然操作** — 用随机源决定元素位置或选择；可产生差异，但仍需由 programme 规定作用范围。（Ch 4, 6, 12）

**Component / 组件** — 某参数下可选择的具体元素或状态。（Ch 1–2）

**Constellation / 星座式组合** — 元素不靠传统线性语法连接，而通过空间、时间或规则形成关系场。（Ch 1, 6, 10–12）

**Constant / 常量** — 跨实例保持稳定，用于维系功能、身份或结构的属性与关系。（Ch 2–3, 7–12）

**Continuity / 连续性** — 元素能通过可测量的中间状态从一种形式过渡到另一种形式；连续不等于步长恒定。（Ch 3, 5, 11–12）

**Evaluation criteria / 评价条件** — 用于筛选组合、判断哪个解在当前条件下更好的准则。（Ch 2）

**Formula / 公式** — 规定元素及其组合关系、能够产生一组形式的 programme 核心。（Ch 1, 11–12）

**Gerstner programme** — 以 Berthold sans serif 为基础，用一致宽度与粗细关系推导字体家族的系统。（Ch 8）

**Grid / 网格** — 当它作为比例调节器并容纳未知内容时，才构成 programme；静态方格本身不是 programme。（Ch 3）

**Integral typography / 整体排印** — 语言和字体、内容和形式、阅读时间和媒介任务互相规定并形成整体。（Ch 10）

**Invariant / 不变量** — 在多种视角或变体中保持为同一对象或关系的核心。（Ch 4–5）

**Morphological box / 形态箱** — 将参数、组件与评价条件系统排列，以探索组合空间的工作结构。（Ch 2）

**Movement / 运动** — 对既有秩序的扰动或重组，使同一元素获得新的关系、重量与整体效果。（Ch 5, 12）

**Open form / 开放字形** — 尽量避免封闭内空间、以开放构形建立字体特征的原则；IBM Original 的重要特征。（Ch 9）

**Parameter / 参数** — 会改变结果、可以独立描述并组织候选值的问题维度。（Ch 2, 11–12）

**Permutation / 置换** — 保留元素集合而改变排列顺序的操作。（Ch 1, 6, 12）

**Programme / 程序** — 一组元素、组合规则和评价条件，用来产生多个具体解，而非固定模板或单一结果。（Ch 1–12）

**Programme as Logic** — 把设计视为条件化选择：可能解有多个，最佳解取决于被明确描述的条件。（Ch 2）

**Proportional regulator / 比例调节器** — 用共同单位和关系协调多种编排的结构，如 mobile grid。（Ch 3）

**Reading-time / 阅读时间** — 展开、翻页、移动或阶段披露使信息在时间中建立节奏与意义。（Ch 10）

**Structure / 结构** — 具有参照系统、在原则上形成自足整体的元素关系。（Ch 7, 11–12）

**Variable / 变量** — 在 programme 允许范围内随内容、媒介、比例或参与者改变的属性。（Ch 2–12）

**Viewer participation / 观看者参与** — 作者规定结构，观看者通过移动、排列或视角完成具体状态。（Ch 11–12）
