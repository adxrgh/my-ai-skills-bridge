# Chapter 2: Morphology and Logic

## Core Idea

设计问题没有无条件的唯一答案。通过 Fritz Zwicky 的 morphological method，把问题完整拆成参数、组件与评价条件，才能发现惯性思维遗漏的解，并说明为什么某个组合在当前条件下更好。

## Frameworks Introduced

- **Programme as Logic**：把设计转化为条件化选择。
  - **When to use**：brief 含糊、方案争论靠偏好、变量众多。
  - **How**：描述问题；写出条件；列可能解；按明确条件选择；条件变化时重新判断。
  - **Why it works**：它把“最佳”从权威断言变成可检查的关系。

- **Morphological Box**：用表格组织参数与组件，系统探索组合空间。
  - **How**：列出决定性维度；为每维列组件；保留临时的 “something else”；生成代表性组合；将重要组件继续细分为新参数。
  - **Failure mode**：blind concatenation 能产生上千组合，却不保证语义或整体。

- **Constants and Variants**：用不变量控制身份，用变量产生适应性。
  - **When to use**：系统需要多个不相同但同源的实例。

- **Formal and Semantic Boxes**：形式分析与语义解释不是同一维度。
  - **How**：先分析字标由哪些形式操作构成，再单独检查这些操作是否解释词义、使用情境或品牌内容。

## Key Concepts

- **Parameter**：决定结果的独立维度。
- **Component**：参数下的候选值。
- **Evaluation criterion**：比较组合的准则。
- **Point of crystallization**：真正使方案获得性格的少数决定参数。
- **Formal operation**：省略、替换、添加、投影、变形等对形式的操作。

## Mental Models

- 形态箱是地图，不是裁判；它展示可走路径，不能决定值得去哪里。
- 当某格不断塞入 “other”，说明问题模型需要升级。
- 一个方案可能由许多参数构成，但通常只有一两个 crystallization points 真正决定它。

## Anti-patterns

- **Absolute solution**：忽略条件，声称某个形式天然正确。
- **Inherited parameter list**：照抄 typogram 表，不根据当前任务建模。
- **Mechanical creativity**：把组合数量当作品质。
- **Semantic afterthought**：形式成立后才强行附会意义。
- **Exhaustive paralysis**：试图穷举全部组合，反而无法学习和选择。

## Reference Table: Typogram Dimensions

| 层级 | 书中示例参数 |
|---|---|
| Basis | word/abbreviation/group、typeface、technique |
| Colour | shade、chromatic/achromatic value |
| Appearance | size、proportion、boldness、inclination |
| Expression | reading direction、spacing、form、design operation |

这些是案例参数，不是跨项目的永久 taxonomy。

## Worked Example

Gerstner 把多个 typogram 放回形态箱分析：Krupp 与 National Zeitung 的决定因素是阅读方向组合；Braun Electric 与 Autokredit 的性格来自间距；Abfälle、Globotyper、wievoll? 使用碎裂、投影或其他字形操作；Auto AG 省略横画，FH 添加瑞士十字，Rheinbrücke 以符号替换部分文字。

分析结果还揭示：形式参数不足以解释意义。Autokredit 的长距离关系可以象征延期付款，Globotyper 的球面投影与名称互相支持。这提示设计还需要一个 semantic box。

## Key Takeaways

1. 描述问题是解决问题的一部分。
2. 参数完整度决定可发现方案的范围。
3. 组合负责发现，评价条件负责选择。
4. 形式分析与语义分析应并行，不要互相冒充。
5. 找出决定方案的少数 crystallization points。
