# Chapter 12: Structure and Movement

## Core Idea

Structure 是带有参照系统的整体；movement 是扰动原有次序、重新赋予元素关系和重量。用同一组元素进行 permutation，可以研究秩序、偶然、对称、反射、旋转、穿插与观看者参与，并让每一阶段成为下一阶段的材料。

## Frameworks Introduced

- **Structure as Self-Contained Order**：元素集合因清楚的次序与参照关系形成整体。
  - **When to use**：需要判断某组规则是否真的建立结构。
  - **How**：声明元素、顺序、边界和参照；检查局部变化后整体关系是否仍可识别。

- **Movement as Disturbance**：移动元素会改变邻接、对比和权重，为整体建立新平衡。
  - **How**：从最小扰动开始；记录哪种关系被打破、哪种关系被保留；逐步增加操作复杂度。

- **Staged Programming with Feedback**：programme 分阶段推进，每阶段积累经验并成为下一阶段材料。
  - **When to use**：复杂系统无法一次建模完成。

- **Order-Chance Continuum**：每个 constellation 是自由选择与预定结果、偶然与秩序的组合。
  - **Decision rule**：高质量差异常来自多个自洽 criteria 的重合，不来自纯随机。

- **Parameter Expansion**：当旧 programme 遇到限制，引入能解释新差异的参数，而不是堆例外。

## Key Concepts

- **Natural order**：如等步长灰阶的基础序列。
- **Cyclic permutation**：把序列末端移到开头而保持循环次序。
- **Interpenetration**：相同或不同群组交错，形成透明和穿插关系。
- **Factorial possibility**：16 个元素拥有 `16!` 种排列，但巨大数量不等于巨大原则数量。
- **Carro 64**：64 个可重排色块组成的参与式 programme。

## Mental Models

- 不要从最复杂图案开始；从基础次序和一次扰动观察关系变化。
- 排列数量可以天文级，但可理解的 ordering principles 仍有限。
- 纯 chance 的输出虽不同，却往往难以区分；可描述秩序更能形成性格。
- 新技术限制可能不是失败，而是发现下一参数的入口。

## Anti-patterns

- **Variant count as richness**：用 `16!` 证明系统丰富，却说不出有意义的分组原则。
- **Chance without invariant**：所有元素完全随机，结果失去身份。
- **Symmetry as automatic quality**：对称关系很多，却与任务或体验无关。
- **One-shot programme**：生成一次系列后封闭系统，不吸收使用和生产经验。
- **Parameter pile-up**：不断增加轴，却不提高解释力。

## Reference Table: Operations

| Operation | 关系变化 |
|---|---|
| Reverse | 次序保留，方向反转 |
| Cyclic permutation | 次序保留，起点移动 |
| Interpose | 让较亮与较暗组交替邻接 |
| Fold/coil | 一维序列进入二维邻接 |
| Reflect | 生成对称与同元素关系 |
| Rotate | 改变方向并生成新整体 |
| Interpenetrate | 多个群组交错成穿插结构 |
| Chance | 降低可见秩序，需保留边界或部分 invariant |

## Worked Example

Gerstner 从 16 个等面积方格和由白到黑的 15 个等步长灰阶开始。交换中间两项、反转、循环置换、交错排列，都会改变对比与邻接；把线性序列折叠进 `4 × 4` 场后，每个元素的邻居从一维的最多两个增加到二维的最多八个。再通过反射、旋转、螺旋和 interpenetration，形成更高层 group of groups。

Carro 64 将这些研究变成 64 个可移动铝方块和可调框架。拥有者可以依规则或偶然重排，作者让出具体构图，却保留色阶、模块和 programme。随后，生产精度问题促使 Gerstner 引入“叠层”参数，发展出 colour levels；印刷限制又推动虚拟浮雕、colour sounds、凹陷 relief 和 colour cube。

这条演化链说明：programme 不是制造大量相似结果的机器，而是积累经验、发现新参数和形成新作品类型的学习装置。

## Key Takeaways

1. Structure 依靠参照关系，不只是元素集合。
2. Movement 是关系重加权，不只是位置动画。
3. 巨大的排列数量不等于丰富的设计原则。
4. chance 应降低或扰动部分秩序，而非抹去全部结构。
5. programme 应以反馈推进，每阶段为下一阶段提供材料。
6. 新参数必须解释真实的新问题。
