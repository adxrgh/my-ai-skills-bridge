# Chapter 3: Grid and Visual Periodicity

## Core Idea

网格只有在作为 proportional regulator、能够容纳未知内容并生成多种编排时，才是 programme。视觉元素的周期性与连续性又使网格超越版面划分，成为控制色调、形状和转换的结构。

## Frameworks Introduced

- **Grid as Proportional Regulator**：网格通过共同单位调节正文、图片、表格和栏位的关系。
  - **When to use**：出版或界面需要多种内容密度与栏结构。
  - **How**：从正文尺度和行距建立单位；选择总宽度与栏间距；验证目标栏数都能无余数组合；测试跨栏与图像。
  - **Why it works**：规则减少任意决定，同时保留内容适配空间。

- **Maximum Conformity, Maximum Freedom**：programme 的难点是让常量尽可能强、变量尽可能丰富。
  - **When to use**：系统要么僵硬，要么失控。

- **Visual Periodicity**：视觉维度、比例、形状和颜色都能被组织为序列或群组。
  - **How**：定义起止状态、周期、步长与闭合关系；让每个中间态仍可测量和解释。

- **Screen as Sign Programme**：印刷网点从白底黑点，经等量棋盘格，到黑底白点，形成色调与形状同步变化的 programme。

## Key Concepts

- **Mobile grid**：可支持多种栏数而共享同一单位的网格。
- **Basic unit**：协调字体、行距、间距和页面宽度的最小尺度。
- **Periodic transformation**：沿序列反复或连续改变元素。
- **Remainder-free division**：各栏组合在单位系统内不产生残余。
- **Integrated arrangement**：多个元素在同一比例原则中协调。

## Mental Models

- 方格纸只是容器；能指导多个未知内容的比例逻辑才是 programme。
- 网格像语法：限制合法关系，但不预写每一页。
- 把网点看成连续变形而非离散图案，就能同时设计形和色调。

## Anti-patterns

- **Grid overlay**：画了很多线，却只能合理地产生一种布局。
- **Mathematics without reading**：整除漂亮，但栏宽、行长和阅读节奏失败。
- **Freedom by exception**：每次内容不适配就绕过网格，而不修正规则。
- **Fixed module worship**：把单位当风格标识，不检查是否来自内容与生产。

## Worked Example

Capital 网格让同一页面宽度同时支持一至六栏。58 个单位看似特殊，实质上是为固定的 2-unit 栏间距和多种栏数求出的共同关系。使用者掌握 key 后，复杂网格变成近乎取之不尽的组合工具。

另一例将印刷 screen 用作制版厂的标志 programme：网点大小改变同时形成明暗和圆—方—圆的形变；四色网点又通过面积关系生成丰富色彩。标志不是任意选择一个网点图形，而是直接使用生产过程自身的结构。

## Key Takeaways

1. Grid 的价值在比例调节，不在可见线条。
2. 规则与自由应同时最大化，而不是彼此让步到平庸。
3. 一个好单位系统能解释多种内容结构。
4. 视觉元素可以按周期和连续关系被 programme 化。
5. 最有力的识别规则常来自对象自身的生产逻辑。
