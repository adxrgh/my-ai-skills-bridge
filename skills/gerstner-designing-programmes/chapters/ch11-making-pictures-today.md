# Chapter 11: Making Pictures Today?

## Core Idea

Programmed picture 不是固定在墙上的单一图像，而可以是一套颜色、比例、材料、机制与观看关系的整体。作者规定观念和组合法则，观看者通过移动作品或自身完成不同但同等有效的 constellation。

## Frameworks Introduced

- **Picture as Participatory Programme**：作者选择元素并规定 grouping laws，观看者完成具体排列。
  - **When to use**：作品希望拥有长期变化、主动观看和多种等价状态。
  - **How**：定义元素；规定观看者可操作部分；确保每个合法状态仍形成完整结构；设计反馈与尺度。
  - **Failure mode**：把未完成与无结构混为一谈。

- **Picture-Formula = Picture-Object**：材料、身体、机制和外形不是承载图像的容器，而是 programme 的组成。
  - **When to use**：作品通过折叠、旋转、反射、光线或空间视角变化。

- **Viewer Movement as Input**：观看者不一定触摸作品；改变视点也可改变具体图像。
  - **How**：为单人近距、多人远距、移动路径和光照变化分别设计。

- **Universal Formula, Personal Perception**：公式越能产生多样而统一的关系，观看者越能获得个人经验。

## Key Concepts

- **Tangential eccentric**：五个偏心圆与切线构成、可旋转产生多种规则 constellation 的作品。
- **Space-wall-picture**：通过多层薄片与观看角度产生变化的空间画面。
- **Picture-object**：物质、结构和图像不可分的整体。
- **Golden-sectioned column**：用比例、灰阶和可旋转环形成多状态的柱状作品。
- **Latent future pictures**：参数组合空间中尚未实现的作品。

## Mental Models

- 把观看关系列入 programme：作品在谁、什么距离、怎样移动时成立？
- 作品的常量可以是 idea，尺寸、颜色与排列可以是变量。
- 光线、反射和观看角度不是外部噪声，可以是正式参数。

## Anti-patterns

- **Participation as gimmick**：可动但每种状态没有结构差异。
- **Object as neutral carrier**：先设计平面，再把材料和机制当制作问题。
- **Single ideal viewpoint**：空间作品只有一个摄影角度成立。
- **Unlimited choice without grammar**：观看者能任意改，却无法形成完整 constellation。
- **Harmony as preset hierarchy**：预设某些比例或颜色天然更高，而不分析组合结构。

## Worked Example

Tangential eccentric 由同轴偏心的五个圆和切线构成，灰阶从白到黑连续。圆可以按最小单位、45°、60°、90°、180°等规则旋转，产生 aleatory 或 regular constellations。作者提供元素和规律，观看者选择具体状态。

Space-wall-picture 的多层薄片让不同角度看到不同部分；观看者移动时，透视、交叠、反射和光线共同形成新整体。Golden-sectioned column 则把九个垂直单元、灰阶序列和可旋转环结合，使同一 constellation 从不同视点继续变化。

这些例子导向更广的原则：画面的外形、材料、构造、位置、比例、颜色和观看方式都应从 idea 重新决定。不是把“picture”预设为矩形平面，而是让 picture-object 由 programme 产生。

## Reference Table: Programme Inputs

| 层面 | 参数示例 |
|---|---|
| Visual | colour、proportion、sequence、contrast |
| Physical | material、body、mechanism、dimension |
| Spatial | distance、angle、planes、reflection |
| Temporal | rotation、movement、light phase |
| Participatory | viewer action、group size、allowed states |

## Key Takeaways

1. 参与式作品需要更精确的规则，而不是更少设计。
2. 观看者、视点和光线可以成为 programme 输入。
3. Picture-object 的材料与机制必须从一开始整合。
4. 作品的 idea 可以恒定，具体 appearance 可以变化。
5. 每个状态都应既独立完整，又能追溯到同一公式。
