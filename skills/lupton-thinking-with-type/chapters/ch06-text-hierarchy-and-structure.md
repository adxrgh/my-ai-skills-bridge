# Chapter 6: Text — Hierarchy and Structure

## Core Idea
Hierarchy is the visual organization of content into clear levels of importance. By manipulating size, weight, posture, color, spatial position, and alignment, typography guides readers through a page or screen, allowing them to skim, prioritize, and digest complex information effortlessly.

## Frameworks Introduced
- **The Structural Contrast Matrix**:
  - When to use: Establishing typographic hierarchy for a project.
  - How: Combine 3 to 5 distinct visual variables to differentiate content levels:
    1. *Size*: Large vs. small (e.g., 36px Title vs. 16px Body).
    2. *Weight*: Light/Regular vs. Bold/Black.
    3. *Posture*: Roman vs. Italic.
    4. *Case*: Uppercase / Small Caps vs. Lowercase.
    5. *Color & Value*: High-contrast black vs. muted grey vs. accent brand color.
    6. *Spatial Position*: Indentation, column placement, and surrounding white space.
- **Minimal vs. Layered Hierarchy Strategy**:
  - When to use: Choosing structural density based on content type:
    - *Minimal Hierarchy*: Uses 1 or 2 subtle cues (e.g., same font size throughout, using only italicization or bold lead-ins for section breaks). Ideal for literary essays, poetry, and minimalist fiction.
    - *Layered Hierarchy*: Uses multiple dramatic visual signals (Kicker $\rightarrow$ Headline $\rightarrow$ Deck $\rightarrow$ Byline $\rightarrow$ Subheads $\rightarrow$ Body $\rightarrow$ Pull Quotes $\rightarrow$ Captions). Essential for magazines, news sites, manuals, and complex dashboards.
- **Inclusive Accessibility Framework**:
  - When to use: Designing accessible web and mobile interfaces.
  - How: Align visual typography with semantic HTML markup and accessibility standards:
    - *WCAG Color Contrast*: Minimum 4.5:1 ratio for normal body text; 3:1 for large display titles.
    - *Semantic Equivalence*: Ensure visual hierarchy maps directly to `<h1>`, `<h2>`, `<h3>`, `<p>` tags for screen readers.
    - *Resizable Text*: Design flexible layout containers that do not clip or break when users increase font size up to $200\%$.

## Key Concepts
- **Kicker (Category Label)**: A short label placed above the main headline to identify the topic or section (e.g., "DESIGN / ARCHITECTURE").
- **Deck (Stand-first)**: A brief introductory paragraph positioned between headline and body copy that expands on the story hook.
- **Pull Quote**: A key sentence extracted from the main text and set in a dramatic large font to hook scanning readers.
- **Type Scale**: A proportional sequence of font sizes generated by multiplying a base size by a constant ratio (e.g., $1.250$ Major Third scale: 12, 16, 20, 25, 31, 39, 49px).
- **Semantic Hierarchy**: Marking text according to its structural meaning rather than just its visual appearance.

## Mental Models
- **Hierarchy as Signal-to-Noise Ratio**: Strong typographic hierarchy increases signal by giving every element a distinct visual job.
- **The 3-Foot / 3-Inch Rule**: In a poster or magazine, the headline must work from 3 feet away; the subhead from 1 foot away; the body text from 3 inches away.

## Anti-patterns
- **Conflict Instead of Contrast**: Using 5 font sizes that are too close in scale (e.g., 14px, 15px, 16px, 17px, 18px), creating visual confusion rather than clear hierarchy.
- **Visual-Only Hierarchy**: Styling text to look like a title using bold `<span>` tags without using proper semantic `<h2>` headings in code.
- **Low-Contrast Accessibility Failure**: Setting light grey body text on a white background (e.g., 2:1 contrast ratio), making it unreadable for low-vision users.

## Reference Tables

### Layered Typographic Hierarchy Blueprint

| Structural Layer | Recommended Size Ratio | Weight / Posture | Spatial Cue | Primary Function |
| :--- | :--- | :--- | :--- | :--- |
| **Kicker** | $0.75\times \text{ to } 0.85\times$ Body | Bold Uppercase / Accent Color | Top of hero block | Section categorization |
| **Main Headline (H1)** | $2.5\times \text{ to } 4.0\times$ Body | Bold / Display Serif or Sans | Full-width hero top | Primary hook & title |
| **Deck (Stand-first)** | $1.25\times \text{ to } 1.5\times$ Body | Medium or Italic | Below headline | Executive summary |
| **Subhead (H2/H3)** | $1.25\times \text{ to } 1.5\times$ Body | Bold / High Contrast | Extra space-before | Scannable section marker |
| **Body Copy** | $1.0\times$ Base ($16\text{px}$) | Regular / Roman | Standard column | Primary reading copy |
| **Pull Quote** | $1.75\times \text{ to } 2.5\times$ Body | Italic or Heavy Accent | Centered / Spans 2 cols | Attention anchor |
| **Caption / Folio** | $0.75\times \text{ to } 0.85\times$ Body | Regular or Medium Grey | Under image / Footer | Utility metadata |

## Worked Example

### Building a Mathematical Type Scale (1.250 Major Third)
1. Set Base Body Size = **16px**.
2. Calculate Scale:
   - **Caption/Folio**: $16 \div 1.250 = \mathbf{12.8\text{px}} \rightarrow 13\text{px}$
   - **Body Text**: $\mathbf{16\text{px}}$
   - **Subhead / Lead**: $16 \times 1.250 = \mathbf{20\text{px}}$
   - **H3 Section**: $20 \times 1.250 = \mathbf{25\text{px}}$
   - **H2 Article Title**: $25 \times 1.250 = \mathbf{31.25\text{px}} \rightarrow 31\text{px}$
   - **H1 Display Hero**: $31.25 \times 1.250 = \mathbf{39.06\text{px}} \rightarrow 39\text{px}$
   - **Mega Display**: $39.06 \times 1.250 = \mathbf{48.8\text{px}} \rightarrow 49\text{px}$
3. Every font size in this system possesses a harmonized geometric relationship to the base text.

## Key Takeaways
1. Hierarchy directs reader attention using scale, weight, color, and position.
2. Ensure contrast is dramatic—subtle size jumps create visual conflict rather than clarity.
3. Use mathematical type scales to maintain proportional harmony across all headings.
4. Align visual hierarchy with semantic HTML structure and accessible color contrast.
