# 设计心理学4：未来设计

**作者**：Donald A. Norman / 唐纳德·A·诺曼 | **页数/章节**：四卷套装 EPUB 中的第 4 卷 | **章节数**：7 | **生成日期**：2026-08-21

- 给主题：从 Topic Index 找到对应章节，再读取该章节。

## 核心框架与心智模型

- **Automation / 自动化**：让机器在一定授权和条件下感知、判断或行动；其边界必须可理解。
- **Human-Machine Team / 人机团队**：把人和机器视为互补协作者，围绕共同目标分配能力和责任。
- **Natural Interaction / 自然互动**：利用人已有的身体、空间和社会技能交互，同时尊重能力与情境差异。
- **Mode Awareness / 模式意识**：人对系统当前控制模式、权限和行为规则的理解。
- **Common Ground / 共同基础**：协作者对目标、状态、意图和知识范围拥有足够共享理解。
- **Graceful Degradation / 优雅降级**：能力或信息不足时安全地降低功能，并保持核心控制与恢复。
- **Future Everyday Things / 未来日用品**：嵌入感知、网络与自主能力，但仍应可理解、可控和适合日常生活的物品。

### 应用纪律

1. 先明确用户、目标、情境与约束，再选择框架；不要反过来为框架寻找例子。
2. 将设计主张写成“当 X 时做 Y，因为 Z”，并指定可观察的成功与失败信号。
3. 区分作者的框架、来源中的案例和你当前项目的假设；三者不能互相冒充。
4. 如果新研究证据与现有方案冲突，修改模型和方案，不修改用户事实。
