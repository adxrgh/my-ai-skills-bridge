# 术语表 — 设计心理学4：未来设计

**Automation / 自动化** — 让机器在一定授权和条件下感知、判断或行动；其边界必须可理解。 (Ch 1、Ch 2、Ch 4、Ch 5)

**Automation Surprise / 自动化惊奇** — 系统行为与人的预期不一致，通常源于隐藏模式、目标或信息不对称。 (Ch 1、Ch 6)

**Calm Technology / 平静技术** — 把信息放在注意力边缘，只在重要时刻进入中心。 (Ch 7)

**Common Ground / 共同基础** — 协作者对目标、状态、意图和知识范围拥有足够共享理解。 (Ch 2、Ch 3、Ch 6)

**Communication Protocol / 沟通协议** — 系统表达意图、状态、不确定性以及请求接管的稳定方式。 (Ch 6)

**Future Everyday Things / 未来日用品** — 嵌入感知、网络与自主能力，但仍应可理解、可控和适合日常生活的物品。 (Ch 7)

**Graceful Degradation / 优雅降级** — 能力或信息不足时安全地降低功能，并保持核心控制与恢复。 (Ch 4、Ch 7)

**Human-Machine Team / 人机团队** — 把人和机器视为互补协作者，围绕共同目标分配能力和责任。 (Ch 2、Ch 5)

**Machine Servitude / 机器的仆人** — 人被迫监控、喂数据、维护和迁就自动化，反而为机器劳动。 (Ch 4)

**Mode Awareness / 模式意识** — 人对系统当前控制模式、权限和行为规则的理解。 (Ch 1、Ch 5)

**Natural Interaction / 自然互动** — 利用人已有的身体、空间和社会技能交互，同时尊重能力与情境差异。 (Ch 3)

**Over-Naturalness / 伪自然** — 模仿人类方式却没有相应理解能力，导致含糊和错误期待。 (Ch 3)
