# 第 7 章：未来的日常用品

## 核心思想

未来物品可以更主动，但必须在日常环境中保持平静、可理解、可控并能在故障时继续基本工作。

## 本章框架

- **Future Everyday Things / 未来日用品**：嵌入感知、网络与自主能力，但仍应可理解、可控和适合日常生活的物品。
  - 何时使用：当为联网、感知或自主设备定义长期产品原则时。
  - 如何使用：冻结核心离线价值，控制注意力请求，公开数据与自动化边界，并设计退化和寿命终点。
  - 失效方式：把云服务、通知和订阅依赖加到本可独立工作的物品上。
- **Calm Technology / 平静技术**：把信息放在注意力边缘，只在重要时刻进入中心。
  - 何时使用：当“未来的日常用品”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Calm Technology / 平静技术”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。
- **Graceful Degradation / 优雅降级**：能力或信息不足时安全地降低功能，并保持核心控制与恢复。
  - 何时使用：当“未来的日常用品”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Graceful Degradation / 优雅降级”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。

## 关键概念

- **Future Everyday Things / 未来日用品**：嵌入感知、网络与自主能力，但仍应可理解、可控和适合日常生活的物品。
- **Calm Technology / 平静技术**：把信息放在注意力边缘，只在重要时刻进入中心。
- **Graceful Degradation / 优雅降级**：能力或信息不足时安全地降低功能，并保持核心控制与恢复。

## 心智模型

- 把本章看成一个决策过滤器：冻结核心离线价值，控制注意力请求，公开数据与自动化边界，并设计退化和寿命终点。
- 当局部界面“看起来合理”却让人迟疑时，回到用户目标、情境和反馈链，而不是继续装饰表面。
- 设计主张必须能被研究证据、行为结果或可用性观察推翻；不能被推翻的主张只是偏好。

## 反模式

- **联网即进步**：把云服务、通知和订阅依赖加到本可独立工作的物品上。
- **术语替代证据**：引用框架名称却没有说明用户、任务、约束和验证信号，会让团队产生虚假的确定性。

## Worked Example

智能门锁应在断网断电时仍提供安全进入方式，低电量提前可见，远程能力不应破坏本地所有权和恢复。

把例子重新应用到自己的产品时，保留同样的推理顺序：先写目标与情境，再写设计动作，最后写可观察的成功/失败信号。

## 关键结论

1. 冻结核心离线价值，控制注意力请求，公开数据与自动化边界，并设计退化和寿命终点。
2. 把“Future Everyday Things / 未来日用品”落实为可观察的界面或流程行为，而不是停留在口号。
3. 用真实情境检查“Graceful Degradation / 优雅降级”，并记录失败条件。
