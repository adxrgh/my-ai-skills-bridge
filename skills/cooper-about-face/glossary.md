# 术语表 — About Face 4：交互设计精髓

**Accessibility / 无障碍** — 把不同感知、运动和认知需求纳入人物模型、流程与细节。 (Ch 16、Ch 19)

**Affordance and Idiom / 能供性与习惯用法** — 能供性提供真实行动可能，习惯用法通过学习形成稳定界面语法。 (Ch 13)

**Controls / 控件** — 供选择、输入、命令和显示的界面构件，其行为应与目标、状态和风险匹配。 (Ch 21)

**Design Collaboration / 设计协作** — 由创造与综合能力互补的小团队共同思考，并与开发和业务持续协作。 (Ch 6)

**Design Principle / 设计原则** — 跨具体界面复用的行为判断规则，用来约束方案而非替代情境。 (Ch 7)

**Design Research / 设计研究** — 通过利益相关者访谈、领域理解和情境式用户观察建立行为证据。 (Ch 2)

**Desktop Posture / 桌面姿态** — 围绕长时、精细、窗口化工作设计命令、选择和对象操作。 (Ch 18)

**Dialogs / 对话框** — 用于必要的集中交互或关键决定；不应成为常规流程和错误报告的垃圾场。 (Ch 21)

**Digital Etiquette / 数字产品礼仪** — 产品应体贴、恭顺、有常识、承担责任并在失败时保持风度。 (Ch 8)

**Direct Manipulation / 直接操作** — 对可见对象进行连续、可逆、快速反馈的操作。 (Ch 13、Ch 18)

**Eliminate Excise / 消除负担** — 移除不直接推进用户目标的导航、记忆、配置、确认和机械步骤。 (Ch 12、Ch 14)

**Error Prevention / 防错** — 通过约束、清晰映射、预览、撤销和非模态反馈避免或减轻错误。 (Ch 8、Ch 15、Ch 21)

**Goal-Directed Design / 目标导向设计** — 以研究得到的人物模型及其目标驱动需求、框架与细节设计的完整过程。 (Ch 1、Ch 6)

**Goal-Directed Task / 目标导向任务** — 直接推进用户目标的活动。 (Ch 12)

**Goals / 目标** — 人希望达到的终态，包括体验目标、最终目标与人生目标；任务只是达到目标的手段。 (Ch 1、Ch 2、Ch 3、Ch 7、Ch 17)

**Information Visualization / 信息可视化** — 以适合比较、因果、模式和多变量理解的视觉编码呈现信息。 (Ch 17)

**Interaction Framework / 交互框架** — 在细节控件前定义产品姿态、屏幕关系、功能分组、关键路径和输入输出。 (Ch 1、Ch 5)

**Interaction Pattern / 交互模式** — 对反复出现问题的情境化解决结构，记录适用条件和权衡。 (Ch 5、Ch 7)

**Learnability / 易学性** — 通过清晰模型、渐进暴露、上下文帮助和一致行为支持掌握。 (Ch 10、Ch 16)

**Mental Model / 心理模型** — 用户对对象、任务与因果的内部理解，界面应优先贴近它而非实现模型。 (Ch 11、Ch 13、Ch 14)

**Mobile Posture / 移动姿态** — 围绕触控、有限空间、短时与情境变化组织导航和动作。 (Ch 9、Ch 19)

**Orchestration and Flow / 编配与流** — 让动作、状态、反馈和过渡形成连续、和谐且少打断的体验。 (Ch 11、Ch 20)

**Perpetual Intermediate / 永久的中级用户** — 大多数用户会离开新手阶段却很少成为专家，界面应主要服务其持续成长。 (Ch 10)

**Persona / 人物模型** — 由研究模式综合出的具体行为原型，用来聚焦设计和避免弹性用户。 (Ch 3、Ch 4)

**Platform Convention / 平台约定** — 用户从操作系统和设备生态带来的稳定预期，偏离需有明确收益。 (Ch 9、Ch 18、Ch 19、Ch 20)

**Posture / 姿态** — 产品在用户注意、使用持续时间和工作环境中的总体行为姿态。 (Ch 9)

**Primary Persona / 首要人物模型** — 其需求可由一个界面完整满足，且若不优先就无法被其他人物模型顺带满足的人物模型。 (Ch 3)

**Progressive Disclosure / 渐进式展开** — 保留常用能力的直接可见性，按需暴露高级复杂性。 (Ch 10、Ch 12、Ch 16)

**Qualitative Research / 定性研究** — 用于发现行为模式、动机、目标和情境，而非估计总体比例。 (Ch 2)

**Refinement / 提炼** — 在框架稳定后完善行为、视觉、术语、状态和边界情况。 (Ch 5、Ch 6)

**Requirements Definition / 需求定义** — 从问题、人物模型、场景和约束推导产品必须提供的能力、信息与情境。 (Ch 4)

**Rich Visual Modeless Feedback / 富视觉非模态反馈** — 在不中断工作流的情况下持续表达状态、范围和结果。 (Ch 11、Ch 15)

**Scenario / 场景** — 以人物模型为主角、围绕目标描述未来使用情境的叙事工具。 (Ch 4)

**Smart Product / 聪明产品** — 利用计算、记忆和预测减少人的机械工作，同时保持透明与控制。 (Ch 8)

**Undo / 撤销** — 依据用户心理模型恢复操作结果，形成可逆历史而非只反转技术命令。 (Ch 15)

**Unified File Model / 统一文件模型** — 减少打开、保存和文件位置管理，让系统持续保存且保留版本。 (Ch 14)

**Visual Hierarchy / 视觉层级** — 用位置、大小、对比、分组和节奏表达结构与优先级。 (Ch 17)

**Web Interaction / Web 交互** — 在页面、滚动、寻路、链接与跨设备约束下维持状态和任务连续性。 (Ch 20)
