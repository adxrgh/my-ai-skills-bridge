# 第 13 章：隐喻、习惯用法及能供性

## 核心思想

成熟界面更多依赖可学习的习惯用法，而非被物理隐喻限制；直接操作也需评估适用性。

## 本章框架

- **Affordance and Idiom / 能供性与习惯用法**：能供性提供真实行动可能，习惯用法通过学习形成稳定界面语法。
  - 何时使用：当团队为“直观”强行模拟现实物体时。
  - 如何使用：区分真实能供性、已学会的习惯用法和装饰隐喻；选择最能支持目标与反馈的方式。
  - 失效方式：隐喻限制数字能力，或把任何拖拽都叫自然。
- **Direct Manipulation / 直接操作**：对可见对象进行连续、可逆、快速反馈的操作。
  - 何时使用：当“隐喻、习惯用法及能供性”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Direct Manipulation / 直接操作”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。
- **Mental Model / 心理模型**：用户对对象、任务与因果的内部理解，界面应优先贴近它而非实现模型。
  - 何时使用：当“隐喻、习惯用法及能供性”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Mental Model / 心理模型”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。

## 关键概念

- **Affordance and Idiom / 能供性与习惯用法**：能供性提供真实行动可能，习惯用法通过学习形成稳定界面语法。
- **Direct Manipulation / 直接操作**：对可见对象进行连续、可逆、快速反馈的操作。
- **Mental Model / 心理模型**：用户对对象、任务与因果的内部理解，界面应优先贴近它而非实现模型。

## 心智模型

- 把本章看成一个决策过滤器：区分真实能供性、已学会的习惯用法和装饰隐喻；选择最能支持目标与反馈的方式。
- 当局部界面“看起来合理”却让人迟疑时，回到用户目标、情境和反馈链，而不是继续装饰表面。
- 设计主张必须能被研究证据、行为结果或可用性观察推翻；不能被推翻的主张只是偏好。

## 反模式

- **隐喻统治**：隐喻限制数字能力，或把任何拖拽都叫自然。
- **术语替代证据**：引用框架名称却没有说明用户、任务、约束和验证信号，会让团队产生虚假的确定性。

## Worked Example

电子日历可借用日历网格帮助理解，但重复事件、搜索和跨时区不应受纸质日历限制。

把例子重新应用到自己的产品时，保留同样的推理顺序：先写目标与情境，再写设计动作，最后写可观察的成功/失败信号。

## 关键结论

1. 区分真实能供性、已学会的习惯用法和装饰隐喻；选择最能支持目标与反馈的方式。
2. 把“Affordance and Idiom / 能供性与习惯用法”落实为可观察的界面或流程行为，而不是停留在口号。
3. 用真实情境检查“Mental Model / 心理模型”，并记录失败条件。
