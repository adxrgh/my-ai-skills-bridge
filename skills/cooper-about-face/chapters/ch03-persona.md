# 第 3 章：为用户建模：人物模型和目标

## 核心思想

人物模型把研究中的行为模式变成稳定设计焦点，目标决定产品行为。

## 本章框架

- **Persona / 人物模型**：由研究模式综合出的具体行为原型，用来聚焦设计和避免弹性用户。
  - 何时使用：当团队以“所有用户”或随讨论变化的弹性用户做决定时。
  - 如何使用：按行为变量聚类，综合人物模型和目标，检查完整与冗余，再指定首要、次要等类型。
  - 失效方式：用人口统计画像、虚构故事或平均用户替代研究模式。
- **Primary Persona / 首要人物模型**：其需求可由一个界面完整满足，且若不优先就无法被其他人物模型顺带满足的人物模型。
  - 何时使用：当“为用户建模：人物模型和目标”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Primary Persona / 首要人物模型”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。
- **Goals / 目标**：人希望达到的终态，包括体验目标、最终目标与人生目标；任务只是达到目标的手段。
  - 何时使用：当“为用户建模：人物模型和目标”相关决策存在多个看似合理的选项时。
  - 如何使用：先标出用户目标与约束，再用“Goals / 目标”逐项检查方案；无法观察或验证的判断不算完成。
  - 失效方式：把术语当标签，却没有改变产品行为或验证方法。

## 关键概念

- **Persona / 人物模型**：由研究模式综合出的具体行为原型，用来聚焦设计和避免弹性用户。
- **Primary Persona / 首要人物模型**：其需求可由一个界面完整满足，且若不优先就无法被其他人物模型顺带满足的人物模型。
- **Goals / 目标**：人希望达到的终态，包括体验目标、最终目标与人生目标；任务只是达到目标的手段。

## 心智模型

- 把本章看成一个决策过滤器：按行为变量聚类，综合人物模型和目标，检查完整与冗余，再指定首要、次要等类型。
- 当局部界面“看起来合理”却让人迟疑时，回到用户目标、情境和反馈链，而不是继续装饰表面。
- 设计主张必须能被研究证据、行为结果或可用性观察推翻；不能被推翻的主张只是偏好。

## 反模式

- **营销画像冒充人物模型**：用人口统计画像、虚构故事或平均用户替代研究模式。
- **术语替代证据**：引用框架名称却没有说明用户、任务、约束和验证信号，会让团队产生虚假的确定性。

## Worked Example

研究显示两类医生在授权和速度上差异明显；分别建模，并选择无法被同一界面顺带满足的一类作为首要人物模型。

把例子重新应用到自己的产品时，保留同样的推理顺序：先写目标与情境，再写设计动作，最后写可观察的成功/失败信号。

## 关键结论

1. 按行为变量聚类，综合人物模型和目标，检查完整与冗余，再指定首要、次要等类型。
2. 把“Persona / 人物模型”落实为可观察的界面或流程行为，而不是停留在口号。
3. 用真实情境检查“Goals / 目标”，并记录失败条件。
