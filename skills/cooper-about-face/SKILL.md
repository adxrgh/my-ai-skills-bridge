## 核心框架与心智模型

- **Goal-Directed Design / 目标导向设计**：以研究得到的人物模型及其目标驱动需求、框架与细节设计的完整过程。
- **Design Research / 设计研究**：通过利益相关者访谈、领域理解和情境式用户观察建立行为证据。
- **Persona / 人物模型**：由研究模式综合出的具体行为原型，用来聚焦设计和避免弹性用户。
- **Goals / 目标**：人希望达到的终态，包括体验目标、最终目标与人生目标；任务只是达到目标的手段。
- **Scenario / 场景**：以人物模型为主角、围绕目标描述未来使用情境的叙事工具。
- **Requirements Definition / 需求定义**：从问题、人物模型、场景和约束推导产品必须提供的能力、信息与情境。
- **Interaction Framework / 交互框架**：在细节控件前定义产品姿态、屏幕关系、功能分组、关键路径和输入输出。
- **Design Principle / 设计原则**：跨具体界面复用的行为判断规则，用来约束方案而非替代情境。
- **Posture / 姿态**：产品在用户注意、使用持续时间和工作环境中的总体行为姿态。
- **Orchestration and Flow / 编配与流**：让动作、状态、反馈和过渡形成连续、和谐且少打断的体验。
- **Eliminate Excise / 消除负担**：移除不直接推进用户目标的导航、记忆、配置、确认和机械步骤。
- **Direct Manipulation / 直接操作**：对可见对象进行连续、可逆、快速反馈的操作。

### 应用纪律

1. 先明确用户、目标、情境与约束，再选择框架；不要反过来为框架寻找例子。
2. 将设计主张写成“当 X 时做 Y，因为 Z”，并指定可观察的成功与失败信号。
3. 区分作者的框架、来源中的案例和你当前项目的假设；三者不能互相冒充。
4. 如果新研究证据与现有方案冲突，修改模型和方案，不修改用户事实。
