## Core Frameworks & Mental Models

### 1. The Tri-Platform Convergence Framework (Ch 01)
Define core editorial brand essence first, then adapt layout mechanics per platform:
- **Print**: Fixed format, tactile pacing, high-resolution physical spreads, baseline grid lock.
- **Web**: Continuous vertical scroll, responsive breakpoints, instant engagement, high-contrast screen typography.
- **Tablet / App**: Touch interactivity, motion/video integration, dual-orientation shifts (portrait single-column vs. landscape multi-column).

### 2. The Format Spectrum Matrix (Ch 02)
Match editorial content density and reader context to the appropriate publication container:
- **Broadsheet / Berliner / Tabloid**: High news density, 4–10 column grids, fast scanning, lightweight newsprint.
- **Consumer Magazine**: Glossy newsstand titles, strong cover branding, high-quality photography, structured section architecture (FOB, Feature Well, BOB).
- **Independent Zine / Micro-Pub**: Niche focus, tactile paper stocks, small print runs, experimental typography.
- **Digital / App Edition**: Interactive galleries, video embedding, liquid responsive layouts, global instant reach.

### 3. The Three Cover Design Taxonomy (Ch 03)
Select cover strategy based on target channel and visual art direction:
- **Figurative Covers**: Focus on human emotion, portraiture, or storytelling photography.
- **Abstract Covers**: Use symbolic graphics, 3D renders, conceptual illustrations, or visual metaphors.
- **Typographic / Text-Based Covers**: Treat giant, expressive typography as the primary hero artwork.
- **Newsstand vs. Subscriber Rule**: Retail newsstand covers require high contrast and dense cover lines; subscriber covers use clean, minimal typography and full-bleed artwork.

### 4. The Three-Zone Publication Architecture (Ch 04)
Structure the page sequence and flatplan into three distinct functional zones:
- **Front-of-Book (FOB)**: Fast-paced, high-density pages (Editor's Letter, Contents, news bites, quick reads).
- **The Feature Well**: The creative core containing long-form stories, deep photo essays, custom DPS layouts, and maximum visual drama.
- **Back-of-Book (BOB)**: Structured, utility-focused pages (reviews, listings, index, columnists).

### 5. The 8 Layout Dynamic Forces Framework (Ch 05)
Orchestrate spatial energy across double-page spreads (DPS):
1. **Scale**: Contrast 1 giant hero element against small, clean text columns.
2. **Contrast**: Juxtapose dark/light, heavy/light weights, dense text/open white space.
3. **Balance**: Symmetrical (formal, serene) vs. Asymmetrical (dynamic, energetic).
4. **Depth**: Layer typography behind cut-out images or across photo contours.
5. **Tension**: Push elements near page margins or trim edges to create energy.
6. **Repetition & Flow**: Use horizontal flowlines across spreads to unify multi-page features.
7. **Implied Motion**: Angle typographic baselines or crop action photos dynamically.
8. **Harmony vs. Discord**: Maintain overall grid alignment (harmony) while intentionally breaking 1 rule (discord) for focal emphasis.

### 6. The Grid Math & Baseline Construction Method (Ch 06)
Build layout grids inside out based on body text typography:
1. **Determine Body Typography**: Select font, size, and leading (e.g., 9.5pt type on 13.5pt leading).
2. **Establish Line Measure**: Target **55–75 characters per line** (print) or **45–65 characters** (screen).
3. **Calculate Live Area & Column Math**: Apply $\text{Live Area} = (N \times \text{Column Width}) + ((N - 1) \times \text{Gutter})$.
4. **Lock Baseline Grid**: Set vertical grid increment to body text leading ($13.5\text{pt baseline grid}$). Snap all headlines, subheads, and image heights to integer multiples ($N \times 13.5\text{pt}$).

### 7. The Design Masters Lineage Model (Ch 07)
Map modern layout techniques to graphic history pioneers:
- **M.F. Agha**: Full-bleed photography, sans-serif display type, unified double-page spread.
- **Alexey Brodovitch**: Dynamic white space, cinematic photo cropping, elegance and movement.
- **Willy Fleckhaus**: Strict 12-column grid system, giant poster typography, black background spreads.
- **Neville Brody / Fabien Baron**: Deconstructed typography, custom experimental fonts, architectural minimalist type.
- **Janet Froelich / Scott Dadich**: Conceptual journalistic photo drama, pioneering interactive multi-touch tablet design.
